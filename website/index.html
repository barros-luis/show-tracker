Installation Notes

First-time setup for each platform

Windows

Windows SmartScreen may show a warning. Click "More info" then "Run anyway".

This is normal for unsigned apps. The app is 100% safe and open-source!

macOS

Run this command once in Terminal to bypass Gatekeeper:

xattr -cr /Applications/AShowTracker.app Removes the quarantine flag from downloaded apps.

Android

Enable "Install from unknown sources" in your device settings before installing the APK.

Required for apps not from the Play Store.

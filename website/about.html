About AShow Tracker

Built by a show enthusiast, for show enthusiasts.

The Vision

AShow Tracker was born from frustration with existing tracking solutions. Web-based trackers feel clunky, and most desktop apps lack visual polish. I wanted something that felt premium—a native app with a beautiful UI that makes tracking shows actually enjoyable.

Built in 2024

What started as a weekend project quickly grew into a full-featured application. Every detail has been carefully crafted—from the glassmorphism effects to the smart notification system that actually tells you when new episodes drop.

Open Source

AShow Tracker is completely free and open source. No ads, no tracking, no premium tiers. The code is available on GitHub for anyone to inspect, contribute to, or learn from.

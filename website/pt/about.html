Sobre AShow Tracker

Construído por um entusiasta, para entusiastas.

A Visão

O AShow Tracker nasceu da frustração com as soluções de rastreamento existentes. Rastreadores baseados na web parecem desajeitados, e a maioria das apps desktop carece de polimento visual. Eu queria algo que parecesse premium—uma app nativa com uma interface bonita que torna o rastreamento de séries realmente agradável.

Construído em 2024

O que começou como um projeto de fim de semana cresceu rapidamente para uma aplicação completa. Cada detalhe foi cuidadosamente elaborado—desde os efeitos glassmorphism até ao sistema de notificações inteligente que realmente te avisa quando novos episódios saem.

Código Aberto

O AShow Tracker é completamente gratuito e de código aberto. Sem anúncios, sem rastreamento, sem níveis premium. O código está disponível no GitHub para qualquer pessoa inspecionar, contribuir ou aprender.

Alimentado por Tecnologia Moderna

Construído com ferramentas que priorizam a performance e a experiência do programador

Tauri

Framework alimentada por Rust para construir apps desktop leves e seguras com tecnologias web.

React

Biblioteca de UI moderna para construir interfaces responsivas e baseadas em componentes.

TypeScript

JavaScript com tipos seguros para apanhar bugs antes de chegarem aos utilizadores.

Supabase

Alternativa open-source ao Firebase para autenticação e base de dados.

Notas de Instalação

Configuração inicial para cada plataforma

Windows

O Windows SmartScreen pode mostrar um aviso. Clica em "Mais informações" e depois em "Executar de qualquer forma".

Isto é normal para apps não assinadas. A app é 100% segura e open-source!

macOS

Corre este comando uma vez no Terminal para contornar o Gatekeeper:

xattr -cr /Applications/AShowTracker.app Remove a flag de quarentena de apps transferidas.

Android

Ativa "Instalar de fontes desconhecidas" nas definições do teu dispositivo antes de instalar o APK.

Necessário para apps que não vêm da Play Store.
